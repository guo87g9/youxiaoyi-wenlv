# 邮小驿 · 一码游高邮

> 一个人、一个 AI、一座城。面向县域文旅的 AI 导览原型，为高邮 17 处景点各配一位「人格化讲解员」。

「邮小驿」是一个**纯静态、零后端**的县域文旅 AI 导览 Web 应用。游客打开即用，无需下载 App；
断网也能讲解、能集章、能查吃住行。目标是解决县域旅游「过境游多、过夜游少」与
「讲解千人一面、内容更新滞后」的老问题。

- 参赛作品：2026 年「一人一驿一 AI」县域文旅赛道
- 交付形态：单文件 HTML（双击即开）/ 静态目录 / 微信小程序（二期）
- **在线演示**：<https://guo87g9.github.io/youxiaoyi-wenlv/>

> 在线版从 `docs/` 发布，不含音频与天地图 key（地图自动降级为手绘示意）。
> 完整体验请用 `交付/` 下的单文件版。

---

## 它解决什么

| 痛点 | 做法 |
|---|---|
| 讲解千馆一面，听完记不住 | 每处景点配一位「人格」讲解员：盂城驿=明代驿丞、文游台=秦少游、汪曾祺纪念馆=汪老本人口吻、镇国寺塔=运河塔灵，其余景点由全域史官「小史」统一讲解 |
| 导游词更新慢、错漏难改 | 内容与代码分离（`data.js` / `data-kb.js`），景区方改一行字即可上线，不必等版本更新 |
| 游客只过境不过夜 | 按官方三大主题线路 + 17 处点位步行时长做规则编排，输出半日 / 一日 / 两日路线 |
| 通用大模型会编历史 | 所有回答先经本地知识库四层归一化检索，命中才答、答必带出处，杜绝虚构史实 |
| 投诉无门、找不到跟进人 | 一键提交诉求，自动签发 `YXY-日期-序号` 单号，可导出转交管理处 |
| 自驾到了找不到车位 | 景点详情页给出经纬度一键复制、跳转导航、检索 1.5 km 内停车场 |

## 快速开始

```bash
git clone https://github.com/guo87g9/youxiaoyi-wenlv.git
cd youxiaoyi-wenlv

# 1. 配置（可选，不配也能跑：地图降级为手绘示意，AI 兜底为固定话术）
cp app/config.example.js app/config.js
#    填入你自己的天地图浏览器端 key：https://console.tianditu.gov.cn/

# 2. 直接用浏览器打开
open app/index.html        # 或者起个静态服务器：python3 -m http.server -d app 8000
```

**推荐直接看交付件**（`交付/` 目录，已内联全部资源）：

| 文件 | 大小 | 说明 |
|---|---|---|
| `邮小驿-单文件版.html` | 1.43 MB | 图片全内联，双击即开 |
| `邮小驿-单文件版-含音频.html` | 20.8 MB | 再加 166 段讲解音频，完全离线 |
| `邮小驿-网页版.zip` | 14.4 MB | 完整静态目录，可部署到任意静态托管 |

## 技术要点

**四层归一化检索（轻量 RAG，不用向量库）**

```
L1 归一化   全角转半角 / 去标点 / 去语气词 / 同义替换 / 简繁统一
L2 实体     命中景点名或别名 → 锁定 spotId（最长匹配）
L3 意图     命中意图词典 + 每条语料自带 intent → 锁定 intent
L4 打分     意图×4 + 实体×3 + 关键词重合×2 + 字符召回×1，过阈值才答
```

县级文旅语料在千条量级，关键词 + 别名的确定性检索比向量库**更稳、更快、可复算**，
且完全离线可跑。自建评测集 **911 条问法，首条命中 909 条 = 99.78%**，脚本随仓库分发：

```bash
node tools/qa_eval.mjs
```

**两级数据加载**：首屏只背 `data.js`（景点 + 音频元数据），`data-kb.js`（201 条问答语料）
按需加载。首屏 **331 KB**（代码 + webp 缩略图，矢量插画另计），弱网可用。

**真实地图而非贴图**：`shared/map.js` 是手写 Canvas Web Mercator 瓦片引擎，零 SDK 依赖，
接天地图 WMTS；无 key 或断网时自动降级为手绘示意地图，入口不失效。

**单文件打包**：`tools/pack_single.py` 把 CSS / JS / 图片（base64）/ 音频（`window.__AUDIO_B64`）
全部内联，输出可 `file://` 直接双击运行的 HTML。

## 目录结构

```
app/                  前端源码（静态，无构建也能跑）
  index.html
  app.js              主逻辑：渲染、问答、集章、诉求单、停车引导
  app.css
  data.js             景点 / 音频元数据（首屏）
  data-kb.js          201 条问答语料（按需加载）
  shared/qa.js        四层归一化检索引擎
  shared/map.js       Canvas 瓦片地图引擎
  assets/             实景照 14 / 插画 SVG 10 / 邮戳 7 / 音频 166
  config.example.js   配置模板（含 tk 留空）
  CREDITS.md          全部素材的版权与来源登记
tools/
  build.py            自检 + 构建 dist / zip / 单文件 / 报告
  pack_single.py      单文件打包器
  qa_eval.mjs         检索评测（可复算 99.78%）
  push_github.sh      一键推送
```

## 构建

```bash
python3 tools/build.py
```

会依次做：`<div>` 标签平衡校验、资源引用完整性、景点 id 与坐标数一致性、音频文件与引用比对、
首屏体积预算（≤350 KB）→ 输出 `dist/`、`交付/*.zip`、两份单文件 HTML、`_build_report.md`。
任一项不过则构建失败。
