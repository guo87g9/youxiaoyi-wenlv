## 七、踩过的坑（别重复踩）

| 坑 | 现象 | 原因与解法 |
|---|---|---|
| `data.js` 拆分后引擎算错 | 评测报"知识库 0 条" | 统计脚本要同时读 `data.js` + `data-kb.js` |
| `suggestFor` 崩 | `Cannot read properties of undefined` | `D.kb` 懒加载前不存在，必须降级 |
| 打字机打断 | 连续提问时上一条丢朗读按钮 | `clearInterval` 要先把上一条 `renderMeta` 补完 |
| 2D/3D 不同步 | 点小按钮大按钮不动 | 用 `yxy:viewmode` 事件统一状态源 |
| PPT 深色卡片写深字 | 文字看不见 | 左右卡配色相反，文字颜色必须分别指定 |
| `window.confirm` 无头测试卡死 | 测试超时 | 必须 `page.on("dialog")` 处理 |
| 天地图底图发白 | 与深绿设计稿不符 | multiply 用 `#3E6B5E` 深墨绿，不是浅薄荷 |
